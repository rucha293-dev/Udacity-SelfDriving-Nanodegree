# Autonomous Driving Engineer Nanodegree 🚗

A complete collection of projects, implementations, and learnings from my Autonomous Driving journey through the Udacity Self-Driving Car / Autonomous Systems program.

This repository covers the core building blocks required to understand and develop autonomous vehicle systems including:

* Control Systems
* Motion Planning
* Sensor Fusion
* Object Detection
* Localization
* Trajectory Generation
* Vehicle Dynamics
* Autonomous Navigation

# Modules Overview

## 📌 Control

This module focuses on vehicle control systems used to stabilize and guide autonomous vehicles.

### Topics Covered

* PID Controller
* Steering Control
* Throttle Control
* Error Minimization
* Vehicle Stability
* Trajectory Tracking

### Key Learning

Control systems convert planned trajectories into smooth and stable vehicle motion.

---

## 📌 ObjectDetection

This section focuses on perception and computer vision fundamentals used in autonomous systems.

### Topics Covered

* Camera Models
* Object Detection Concepts
* Bounding Boxes
* Image Processing
* Perception Pipelines
* Lens Distortion Correction

### Key Learning

Perception enables vehicles to understand their surroundings and identify important objects in real time.

---

## 📌 Planning

This module contains trajectory generation and motion planning implementations.

### Topics Covered

* Behavioral Planning
* Path Planning
* Motion Planning
* Polynomial Spiral Optimization
* Velocity Profile Generation
* Goal State Computation

### Key Learning

Planning combines mathematics, optimization, and decision-making to generate safe vehicle trajectories.

---

## 📌 Scan_matching_localization

This section focuses on localization techniques used for estimating vehicle position.

### Topics Covered

* Localization
* Scan Matching
* Pose Estimation
* Coordinate Transformations
* Sensor Alignment
* Map Matching Concepts

### Key Learning

Localization is one of the most critical parts of autonomy because every planning and control decision depends on accurate positioning.

---

## 📌 Sensor_Fusion

This module focuses on combining multiple sensor inputs to improve environmental understanding.

### Topics Covered

* Kalman Filters
* Sensor Fusion
* Multi-Sensor Tracking
* State Estimation
* Noise Reduction
* Sensor Uncertainty

### Key Learning

Sensor fusion improves reliability by combining information from multiple sources like cameras, LiDAR, radar, and GPS.
